
# Experiment Figures

Figures generated during the experiments are stored under `reports/figures/`, organized by project.

## Image classification

| File | Description |
|---|---|
| `image_classification/class_samples.png` | Twenty sample images: five examples from each of the four selected vegetable classes. |
| `image_classification/confusion_matrix.png` | Confusion matrix for the vegetable classifier. |
| `image_classification/classification_result.png` | Classification result visualization from the image-classification experiment. |

## Stock forecasting

| File | Description |
|---|---|
| `stock_forecasting/historical_closing_prices.png` | Historical TSLA adjusted closing prices. |
| `stock_forecasting/daily_percentage_returns.png` | Daily percentage returns for TSLA. |
| `stock_forecasting/gru_train_val_loss.png` | GRU training and validation loss. |
| `stock_forecasting/forecast_error.png` | Forecast error diagnostics for the univariate GRU experiment. |

These figures document the experiments and their results. They should not be interpreted as evidence of real-world generalization beyond the evaluation described in the accompanying documentation.
